# 校園守護者

國小校園安全教育 RPG 遊戲，內容包含防災、交通安全、性別平等、反霸凌、校園常規五大主題。

## 立即遊玩

https://ch60125-dotcom.github.io/safety-rpg/

電腦、平板、手機的瀏覽器都可以直接開啟，不需安裝。

## 操作方式

方向鍵或 WASD 移動，空白鍵或 Enter 對話、確定，數字鍵 1 到 4 作答，Q 任務清單，M 小地圖。平板可用畫面上的方向鍵。

## 遊戲目標

和校園裡五位老師對話、答題打倒怪獸，收集 5 枚守護徽章後到校長室挑戰大魔王，完成後可列印獎狀。

## 老師修改題庫

開啟 index.html，最上方「老師可修改區」的 QUIZ 即為題庫。選擇題的第一個選項是正確答案，遊戲會自動打亂順序。SCHOOL_NAME 可修改校門口顯示的校名。
