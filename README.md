# 校園的日常

國小校園安全教育 RPG 遊戲，內容包含防災、交通安全、性別平等、反霸凌、校園常規五大主題。

## 立即遊玩

https://ch60125-dotcom.github.io/safety-rpg/

電腦、平板、手機的瀏覽器都可以直接開啟，不需安裝（手機請轉成橫向）。開始時輸入「班級＋暱稱」（排行榜會公開顯示，請不要使用真實姓名，像真名的暱稱會被擋下來）。

老師的課堂用法請看〈[老師課堂使用說明](老師課堂使用說明.md)〉。

## 操作方式

| 按鍵 | 功能 |
|---|---|
| 方向鍵 / WASD | 移動 |
| 空白鍵 / Enter | 對話、確定 |
| 數字鍵 1～4 | 作答 |
| Q | 任務清單（含隱藏任務、造型、換裝） |
| B | 道具 |
| M | 小地圖 |
| R | 排行榜 |

平板、手機可使用畫面左下角的方向鍵和右下角的「對話」按鈕。首頁可以關掉音效，或把地震反應時間從 3 秒改成 6 秒。答題時可按「🔈 唸給我聽」朗讀題目。

## 遊戲內容

- **五大主題挑戰**：和五位老師對話，答題打倒怪獸，收集 5 枚守護徽章後到校長室挑戰大魔王，完成後可列印獎狀。每個主題 20 題，不重複出題，答錯的題目之後會再複習。
- **校園隨機事件**：地震、下雨、陌生人搭訕、群組霸凌訊息、同學跌倒、垃圾分類等，考驗臨場判斷。
- **老師關心**：生教組長會在校園巡堂，主動關心學生、在挑戰失敗時給予提示。
- **隱藏任務**：共 5 個，完成可獲得特別造型。
- **紙娃娃換裝**：開始前可自選髮型、髮色、膚色、上衣、褲子和配件，遊戲中也能在任務清單裡換裝。
- **戰鬥**：連續答對 3 題是「會心一擊」，會回復 1 顆愛心。大魔王分三個階段，血越少題目越難。
- **道具欄**：提示卡、愛心飯糰、守護盾、指南針，跟校園裡的大人聊天、升級、處理隨機事件或完成隱藏任務就能取得。
- **金徽章**：拿到徽章後回去找老師練習，一題都不答錯，徽章會升級成 🌟 金徽章。
- **校園地圖**：依照學校真實的校園配置。北邊的安翠樓由西到東是性別友善廁所、音樂教室、總務處、校長室、電腦教室、英語教室、健康中心、圖書館、美術教室；中間是幼兒園（有繪本、積木、搖搖馬，吳老師會提醒大家照顧學弟妹）和南耘樓的防災教育中心、輔導室、教室；一進校門右邊有大象溜滑梯造型的藝術裝置（只能欣賞，不能玩），小孔廟後面有一座假山；司令台左邊還有一間性別友善廁所。北面光電球場左邊是籃球全場、右邊是排球場；南邊有操場、南面光電球場（半場籃球場和兩面匹克球場）、小孔廟、菜圃和榕樹區，最東邊是小溪和溪畔步道，校門口大道兩旁種著椰子樹，南大門外是馬路。
- **英語教室、音樂教室**：彭老師教你生活中常用的英文，李老師分享保護聽力的方法，答對小問題可以拿到道具。
- **性別友善廁所**：校園裡有兩間，每間 4 間隔間都可以走到門前上廁所（選上小號或上大號），提醒大家對準、沖水、保持乾淨，上完再到洗手台洗手。在廁所裡不會跳出隨機事件，老師也不會來搭話。
- **小遊戲**：音樂教室可以彈鋼琴（跟著發亮的琴鍵彈〈小星星〉〈小蜜蜂〉〈生日快樂〉）；電腦教室有「檔案打地鼠」，作業、照片、老師的通知這些正常檔案才點，病毒和詐騙訊息不能點；輔導室的沙發可以進入「心情小花園」，選心情、跟著泡泡深呼吸、抽一張暖心卡，再自由種花；防災教育中心可以用練習滅火器練習「拉、瞄、壓、掃」，面向器材櫃還能進行「地震模擬」（趴下掩護穩住、主震結束後聽到「1 長 4 短」哨音再準備疏散、在原教室戴防災頭套或在科任教室用書包護頭、依校園防災地圖路線疏散、班導師到指揮中心回報人數）和「火災模擬」（大喊失火、小火快逃、濃煙關門、不搭電梯、停躺滾）；小孔廟可以玩「投壺」（先對準壺口、再抓好力道，把 8 支箭投進壺裡，認識古代的禮儀遊戲）；美術教室的畫架可以畫畫（有題目、12 種顏色、橡皮擦、復原，畫好還能存成圖片）。第一次完成有小獎勵，不計入積分。
- **一年甲班林老師**：會在校園裡到處走動，每次聊天都有不同的生活叮嚀。
- **過馬路**：如果紅燈了還在斑馬線上，導護志工方阿伯會過來帶你安全走到對面。
- **處室組長與主任**：體育組徐組長（運動安全）、衛生組許組長（打掃與衛生）、總務處林主任（校園建設與修繕）、資訊組蕭組長（在電腦教室說明資訊安全）、事務組陳老師（在總務處說明怎麼報修、愛護班級設備）、美術教室邱老師（美勞工具的安全使用），答對小問題也能拿到道具。
- **排行榜**：可查看全校與班級前 20 名。遊戲時間約 30 分鐘。

## 守護積分

| 項目 | 分數 |
|---|---|
| 各主題過關那一場：答對 / 答錯 | +10 / −5 |
| 第一次挑戰就過關 | +30 |
| 打倒大魔王（第一次就打倒再 +50） | 答對 +10、答錯 −5，再 +100 |
| 完成一個隱藏任務 | +20 |

滿分 750 分。練習模式、小問答和隨機事件不計分。答了第一題才算一次挑戰，還沒作答就撤退，不會失去「第一次就過關」的加分。

## 老師修改題庫

開啟 `index.html`，最上方「老師可修改區」：

- `QUIZ`：題庫。選擇題的第一個選項是正確答案，遊戲會自動打亂順序；排序題 `type:'order'` 的 `items` 依正確順序填寫。
- `SCHOOL_NAME`：校門口顯示的校名。
- `SCRIPT_URL`：排行榜的 Google Apps Script 網址。
